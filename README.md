# World Of Music (WOM)

Дипломный проект — веб-платформа для музыкального образования, объединяющая педагогов, учеников и родителей в единой системе.

**Автор:** Казанова Милана Жабагиевна

## О проекте

World Of Music — это Django-приложение для музыкальных школ и частных педагогов. Платформа реализует ролевую модель доступа (педагог, ученик, гость/родитель), публичный каталог музыкальных произведений и личные кабинеты с учётом уроков, назначений и исполнений учеников.

### Возможности

- Регистрация и авторизация с разделением ролей: педагог, ученик, гость
- Модерация педагогов администратором перед предоставлением доступа
- Личные кабинеты педагога и ученика с историей уроков и исполнений
- Публичный каталог педагогов, произведений, композиторов и жанров
- Загрузка и хранение учебных материалов, видео исполнений и нот
- Комментарии педагога к исполнениям учеников

## Технологический стек

- **Backend:** Python 3.12, Django 6.0
- **База данных:** PostgreSQL 16
- **Кеширование:** Redis 7
- **Frontend:** Bootstrap 5
- **Контейнеризация:** Docker, Docker Compose

## Структура проекта

Проект разделён на четыре Django-приложения:

- `accounts` — пользователи, аутентификация, роли, профили
- `education` — уроки, назначения педагог-ученик, исполнения, оценки
- `music` — каталог произведений, композиторы, жанры, инструменты
- `core` — главная страница, общие шаблоны и статические файлы

## Запуск проекта

Проект запускается в Docker-контейнерах: веб-приложение, база данных PostgreSQL и Redis поднимаются одной командой.

### Требования

- Docker
- Docker Compose

### Шаги запуска

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <ссылка-на-репозиторий>
   cd WorldOfMusic
   ```

2. Создайте файл `.env` в корне проекта (рядом с `docker-compose.yml`) со следующим содержимым:

   ```env
   POSTGRES_DB=wom_db
   POSTGRES_USER=wom_user
   POSTGRES_PASSWORD=qwer
   POSTGRES_HOST=db
   POSTGRES_PORT=5432
   ```

3. Соберите и запустите контейнеры:

   ```bash
   docker-compose up --build
   ```

   Эта команда поднимет три сервиса:

   - `db` — PostgreSQL с проверкой готовности (healthcheck)
   - `redis` — Redis для кеширования
   - `web` — Django-приложение на порту 8000

4. В отдельном терминале примените миграции:

   ```bash
   docker-compose exec web python manage.py migrate
   ```

5. Создайте суперпользователя для доступа к админ-панели:

   ```bash
   docker-compose exec web python manage.py createsuperuser
   ```

6. Откройте приложение в браузере:

   - Сайт: [http://localhost:8000](http://localhost:8000)
   - Админ-панель: [http://localhost:8000/admin](http://localhost:8000/admin)

### Остановка контейнеров

```bash
docker-compose down
```

Данные PostgreSQL сохраняются в volume `postgres_data` и не удаляются при остановке контейнеров. Чтобы удалить и данные тоже, используйте:

```bash
docker-compose down -v
```

## Запуск без Docker (локально)

1. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Настройте `.env` в папке `config/` с параметрами подключения к локальной PostgreSQL.

4. Примените миграции и запустите сервер:

   ```bash
   cd config
   python manage.py migrate
   python manage.py runserver
   ```

## Вход через Google (опционально)

Помимо логина/пароля, сайт поддерживает вход по email, телефону и через Google.
Вход по email/телефону работает сразу, без дополнительной настройки. Для входа
через Google нужны собственные учётные данные — Anthropic/сторонние сервисы их
предоставить не могут, только сама Google.

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/) → создайте проект.
2. В разделе **APIs & Services → OAuth consent screen** заполните минимальные данные (тип — External, для разработки достаточно).
3. В разделе **Credentials** нажмите **Create Credentials → OAuth client ID**, тип приложения — **Web application**.
4. В **Authorized redirect URIs** укажите точно:
   ```
   http://127.0.0.1:8000/accounts/google/callback/
   ```
   (для продакшена — такой же адрес, но с вашим доменом вместо 127.0.0.1:8000)
5. Скопируйте **Client ID** и **Client Secret** и добавьте их в `.env`:
   ```env
   GOOGLE_OAUTH_CLIENT_ID=ваш_client_id
   GOOGLE_OAUTH_CLIENT_SECRET=ваш_client_secret
   GOOGLE_OAUTH_REDIRECT_URI=http://127.0.0.1:8000/accounts/google/callback/
   ```

Пока переменные не заданы — кнопка «Войти через Google» просто покажет сообщение
«вход через Google пока не настроен», без ошибок.

## Роли пользователей

| Роль | Доступ |
|---|---|
| Гость | Просмотр публичного каталога и списка педагогов |
| Ученик | Личный кабинет, свои уроки и исполнения |
| Педагог | Управление учениками, уроками, назначениями (после одобрения администратором) |
| Администратор | Полный доступ через админ-панель Django |
