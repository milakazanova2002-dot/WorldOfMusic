# 2. Music — музыкальная библиотека

Созданы модели:

## Composer
Хранит информацию о композиторах:

- имя;
- фамилия;
- биография.

## Genre
Хранит музыкальные жанры.

## Instrument
Хранит музыкальные инструменты.

## MusicalPiece
Хранит музыкальные произведения.

Связи:

- произведение → композитор (`ForeignKey`);
- произведение → жанры (`ManyToMany`);
- произведение → инструменты (`ManyToMany`).

Настроена админка.

Добавлены русские названия моделей через:

- `verbose_name`
- `verbose_name_plural`

Созданы тестовые данные:

- жанр;
- инструмент;
- музыкальное произведение.
